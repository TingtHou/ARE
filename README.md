# ARE Study System

Study site for ARE 5.0 PA, PPD and PDD: dashboard, study notes, spaced-repetition flashcards, timed practice, a mistake log and the 14-week plan.

- `index.html` is the page served by GitHub/AWS Amplify (generated; run `build-index.ps1` after changing `are-study-system.html`)
- `are-study-system.html` is the page source, also published to claude.ai
- `material/` holds all study content. See `material/README.md` for how to edit it.

Progress is saved in each browser. On the claude.ai version it also syncs to your account.
